# Molino 32 · Práctica 4

Tienda de café de especialidad hecha con HTML, CSS, JavaScript, PHP y MySQL para la práctica 4 de Programación Web Avanzada.

- Sitio: https://pwpractica4.infinityfree.io/
- Repositorio: https://github.com/jorgevillamar369-glitch/pwapractica4

## Tecnologías

PHP 8, MySQL, HTML, CSS y JavaScript. La base de datos está en `sql/pwapractica4.sql` y la conexión se configura en `config/db.php`.
